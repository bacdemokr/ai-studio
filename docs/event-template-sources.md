through the crew brief, generated event page and Excel plan.

## Event page design references

Visually checked on 2026-09-24:

- [NVIDIA AI Day](https://www.nvidia.com/en-us/ai-days/): centered section headings,
  generous spacing and straightforward event cards.
- [NVIDIA at CVPR](https://www.nvidia.com/en-us/events/cvpr/): text-first session
  cards with title, metadata, description and an action link.

The local starter adapts these patterns to light content sections. It is a
project-authored planning template, not an official NVIDIA announcement.
